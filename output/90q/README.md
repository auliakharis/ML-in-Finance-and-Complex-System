# 90q

A benchmark of ~90 compositional financial questions generated by the compiler pipeline, covering a range of operator types and expression tree depths.

## Contents

| File | Description |
|---|---|
| `random_questions_90.json/csv` | Original 90 questions sampled from the compiler pipeline |
| `random_questions_90_new.json/csv` | Revised/extended question set |
| `random_questions_90_augmented.json/csv` | Augmented version with additional metadata (used for multi-turn eval) |
| `final_90_questions_mixed.json/csv` | Final merged set with mixed operator types and depths |
| `financial_spreadsheet.json/csv` | Financial data table used as context for all 90q questions |
| `generated_operator_tree.json` | Sampled expression tree from the compiler pipeline |

## Question Format

Each question record includes:
- `question_id` — unique identifier
- `question` — natural language question
- `answer` — ground-truth numeric answer
- `expression_json` — the expression tree that produces the answer
- `bound_expression_depth` — depth of the expression tree (0 = single lookup, 1+ = compositional)
- `leaf_*` fields — individual data lookups that feed into the expression

## Relationship to compiler_pipeline

Questions here are produced by `compiler_pipeline/5.make_random_questions.py` and then filtered/augmented. The `financial_spreadsheet.json` is the binding of synthetic company data to the expression tree leaves.

# industry_analysis

Analyzes the distribution of fiscal years and quarters across companies in the generated 10-Q dataset.

| File | Description |
|---|---|
| `fiscal_year_distribution.py` | Counts and plots fiscal year / quarter distributions by industry |
| `fiscal_year_raw.csv` | Raw per-company fiscal year data |
| `fiscal_year_distribution.csv` | Aggregated distribution counts |

Run `fiscal_year_distribution.py` after generating reports to verify that the synthetic data covers years and industries evenly.
